## Hi, I'm Vaeeshnavi

I'm a data analyst in Pune. For the last five years I've looked after product and material data in SAP PLM for a global FMCG client, across plants in six countries. Most of my work is finding out why a number is wrong, fixing it at the source and making sure it stays fixed.

On GitHub I build projects around problems I've seen at work: duplicate records, missing data, and reports nobody trusts.
